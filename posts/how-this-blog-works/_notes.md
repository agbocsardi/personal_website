# How This Blog Works — Raw Notes

## Core angle
- Gergő is a PhD student — writes words for a living, tired of typing
- Blog adds more writing on top of an already writing-heavy life → too much friction
- Wants AI assistance but: putting own name on AI-written content without disclosure = dishonest
- But "my name + AI disclosure" feels weird/clunky
- Solution: own the weird. It's his blog, he makes the rules.
- **Watson-style narrator**: agent writes about Gergő in third person. Fully honest format — not pretending to be human-written.
- Lets him get thoughts out without sitting down to type full posts
- Low-friction: voice notes, Telegram rants, quick notes on walks → agent shapes into posts

## Key beats to hit
1. The friction problem (too many words already)
2. The honesty dilemma (AI disclosure + personal blog = awkward)
3. The Watson solution (third-person narrator, honest by design)
4. The actual workflow (dump thoughts → agent asks questions → agent researches → agent writes → Gergő edits)
5. Why it's interesting as an experiment

## Tone
- Personal, honest, a bit meta
- Watson narrator voice (Cody writes this in first person about Gergő)
- Not defensive, not salesy — just explaining the setup
